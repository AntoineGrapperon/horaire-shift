# User Stories: Templates & Structural Planning

## US.10 - Typical Week Definition
**As a** Manager  
**I want to** define a "Typical Week" template specifying shifts (Day, Night, Evening), start/end times, and required competencies  
**So that** I have a reusable structural baseline for my department's needs.

## US.11 - Cycle Application
**As a** Manager  
**I want to** apply my "Typical Week" template to a specific date range (e.g., a 3-month quarter)  
**So that** the system automatically generates the "empty" shifts that need staffing for that period.

## US.13 - Capacity Check
**As a** Manager  
**I want to** see a comparison between the total hours required by my template and the total contracted hours available from my staff  
**So that** I can identify structural staffing shortages before I even start assigning people.
