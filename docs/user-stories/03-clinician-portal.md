# User Stories: Clinician Portal

## US.4 - Mobile Calendar View
**As a** Clinician  
**I want to** see my assigned shifts in a clear, mobile-responsive calendar  
**So that** I always know when I am expected to work without checking paper lists.

## US.5 - Digital Shift Swapping
**As a** Clinician  
**I want to** propose a shift swap to a qualified colleague within the app  
**So that** the process is tracked and requires final manager approval before the schedule updates.

## US.6 - Availability & Preferences
**As a** Clinician  
**I want to** input my "preferred off" dates for the upcoming 3-month cycle  
**So that** the solver can attempt to respect my work-life balance while filling the template.
