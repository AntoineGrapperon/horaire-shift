# User Stories: Resource Assignment & Solving

## US.1 - One-Click Assignment
**As a** Manager  
**I want to** trigger the automated solver to assign staff to a 3-month block of templated shifts  
**So that** I don't have to manually match 30+ employees to hundreds of shifts.

## US.2 - Skill-Based Matching
**As a** Manager  
**I want to** ensure that the solver only assigns staff to shifts they are qualified for (e.g., Senior Nurse for ICU shifts)  
**So that** departmental safety standards are maintained.

## US.3 - Manual Adjustments
**As a** Manager  
**I want to** manually swap or reassign staff after the solver has run  
**So that** I can account for human factors or specific nuances the algorithm might miss.
